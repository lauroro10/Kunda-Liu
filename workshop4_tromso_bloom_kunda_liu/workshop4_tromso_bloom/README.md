# Tromsø Bloom

**Name:** Tromsø Bloom  
**Date:** 16 March 2026  
**Author:** Kunda Liu

## Instructions
1. Open `index.html` in a browser or run the project with a local server.
2. Allow camera access when prompted.
3. Face the camera.
4. Open your mouth to brighten and intensify the aurora.
5. Close your mouth to return the aurora to a calmer state.
6. Press `D` to show or hide the debug view.

## Blurb
This is a machine-seeing sketch inspired by seeing the aurora in Tromsø. The work uses FaceMesh to detect mouth opening and translates that small bodily movement into a larger environmental change. The aurora becomes brighter, thicker and more active when the mouth opens, then slowly returns to a quieter state.

## Project files
- `index.html` — loads p5.js, ml5.js and the sketch.
- `style.css` — basic page styling.
- `sketch.js` — FaceMesh input and visual rendering.
